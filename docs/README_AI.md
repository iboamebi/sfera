# Sfera AI Documentation Index

Этот раздел содержит документы для восстановления контекста проекта при работе с ИИ.

## Основные документы

### AI_CONTEXT.md

Краткое описание проекта:

- назначение;
- стек;
- архитектура;
- текущая стадия разработки;
- основные правила.


### ARCHITECTURE.md

Архитектурная конституция проекта:

- DDD;
- Clean Architecture;
- слои приложения;
- зависимости между слоями;
- правила миграции.


### MIGRATION_STATUS.md

Текущий технический статус:

- что уже перенесено;
- что находится в работе;
- следующий шаг.
