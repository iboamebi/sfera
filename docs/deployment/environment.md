# Окружение проекта «Сфера»

**Версия:** 1.1
**Дата актуализации:** 2026-07-16

---

# 1. Назначение

Документ описывает требования и правила настройки окружения для запуска проекта «Сфера».

---

# 2. Архитектура окружения

Текущая схема:

```text
Client Browser

↓

FastAPI Application

↓

PostgreSQL Database

↓

External Storage
```

---

# 3. Сервер

Основное окружение:

```text
Linux Mint Server
```

---

# 4. Backend

Технологии:

```text
Python 3.12

FastAPI

Uvicorn

SQLAlchemy

Alembic
```

---

# 5. База данных

Используется:

```text
PostgreSQL
```

Параметры:

```text
Database:

sphere
```

Миграции:

```text
Alembic
```

---

# 6. Виртуальное окружение

Используется:

```text
.venv
```

Активация:

```bash
source .venv/bin/activate
```

---

# 7. Запуск приложения

Команда запуска:

```bash
uvicorn app.main:app --host 0.0.0.0
```

---

# 8. Docker

Docker и Docker Compose доступны для дальнейшего использования.

Планируемое применение:

- развёртывание;
- тестовое окружение;
- изоляция сервисов.

---

# 9. Сетевой доступ

Удалённый доступ осуществляется через:

```text
ZeroTier
```

Используется для:

- доступа разработчиков;
- удалённого подключения;
- внутренних сервисов.

---

# 10. Локальный DNS

Используется собственная DNS-схема для ZeroTier.

Компонент:

```text
dnsmasq
```

Назначение:

- внутреннее разрешение имён;
- независимость от внешних сервисов.

---

# 11. Переменные окружения

Настройки хранятся:

```text
.env
```

Необходимо хранить отдельно:

- параметры базы данных;
- секреты;
- ключи доступа;
- настройки интеграций.

---

# 12. Git

Основная ветка:

```text
develop
```

Репозиторий:

```text
GitHub
```

Правила:

- изменения выполняются через commits;
- история сохраняется;
- рабочие версии не теряются.

---

# 13. Документация

Документация проекта находится:

```text
docs/
```

Структура:

```text
docs/

├── architecture

├── database

├── modules

├── api

└── deployment
```

---

# 14. Резервное копирование

Должно обеспечиваться резервирование:

- базы PostgreSQL;
- документов;
- конфигурации;
- исходного кода.

---

# 15. Главный принцип

Окружение проекта должно быть воспроизводимым и обеспечивать стабильную работу системы на всех этапах разработки и эксплуатации.
