# API Layer

**Версия:** 1.1
**Дата актуализации:** 2026-07-16

---

# 1. Назначение

API Layer является внешним интерфейсом системы «Сфера».

Он обеспечивает взаимодействие клиентов с приложением через HTTP REST API.

---

# 2. Место в архитектуре

```text
Client

↓

API Router

↓

Application Service

↓

Domain

↓

Infrastructure
```

---

# 3. Ответственность API

API отвечает за:

- обработку HTTP-запросов;
- валидацию входных данных;
- сериализацию ответов;
- аутентификацию;
- авторизацию;
- формирование HTTP-ошибок.

---

# 4. Расположение

```text
app/api/
```

---

# 5. Структура

```text
api/

├── routers/
├── dependencies/
├── middleware/
└── exceptions/
```

---

# 6. Router

Router является тонким слоем.

Он выполняет:

1. Получение запроса.
2. Проверку входных данных.
3. Вызов Application Service.
4. Формирование ответа.

---

# 7. Запрещено в Router

Не допускается:

- бизнес-логика;
- SQL-запросы;
- работа с ORM;
- управление транзакциями;
- изменение состояния Domain напрямую.

---

# 8. Schemas

API использует Pydantic-схемы.

Расположение:

```text
app/schemas/
```

Назначение:

- входные данные;
- выходные данные;
- OpenAPI описание.

---

# 9. Типы схем

## Create

Создание объекта:

```text
OrderCreate
```

---

## Update

Изменение объекта:

```text
OrderUpdate
```

---

## Response

Ответ API:

```text
OrderResponse
```

---

# 10. Маршруты

Основные группы API:

```text
/customers

/orders

/order-items

/instruments

/verifications

/diagnostics

/repairs

/warehouses

/materials

/documents

/price-lists
```

---

# 11. Ошибки

API преобразует внутренние ошибки в HTTP-ответы.

Пример:

```text
EntityNotFound

↓

404 Not Found
```

---

# 12. Версионирование

Планируемая структура:

```text
/api/v1/
```

Пример:

```text
/api/v1/orders
```

---

# 13. Безопасность

API отвечает за:

- идентификацию пользователя;
- проверку токена;
- проверку разрешений.

Бизнес-ограничения доступа находятся в Application и Domain.

---

# 14. Документация API

FastAPI автоматически предоставляет:

Swagger:

```text
/docs
```

OpenAPI:

```text
/openapi.json
```

---

# 15. Тестирование

API покрывается:

- тестами маршрутов;
- проверкой HTTP-кодов;
- проверкой валидации;
- интеграционными тестами.

---

# 16. Главный принцип

API является только транспортным слоем.

Вся бизнес-логика должна находиться в Application и Domain.
