Используется:

- PEP8

# Типизация

Типизация обязательна.

Пример

```python
def create_order(order: OrderCreate) -> Order:
    ...
```

Использование `Any` допускается только в исключительных случаях.

---

# Комментарии

Комментарии пишутся только там, где код невозможно понять без пояснений.

Не допускаются комментарии вида

```python
# создаём список
items = []
```

Допускаются

```python
# Аршин требует экспорт только завершённых поверок.
```

Используется новый стиль SQLAlchemy 2.0.

Обязательно

```

relationship
```

Не использовать старый стиль Column().

# Бизнес-логика

Запрещено размещать бизнес-логику:

- в моделях;
- в Router;
- в CRUD.

Она размещается в Service и Domain.

---

# CRUD

CRUD содержит только операции доступа к данным.

---

# Router

Router:

- принимает запрос;
- вызывает сервис;
- возвращает ответ.

---

# Service

Service:

- реализует бизнес-правила;
- управляет транзакциями;
- вызывает Repository.

---

# Repository

Repository работает только с БД.

---

# Доменные события

Доменные события должны наследоваться от DomainEvent.

Отправка производится через EventDispatcher.

---

# Unit of Work

Все операции изменения данных выполняются через Unit of Work.

---

# Alembic

Любое изменение модели сопровождается новой миграцией.

Редактирование старых миграций запрещено.

---

# Тестирование

Для каждого нового модуля создаются тесты:

- модели;
- сервиса;
- API.

---

# Запрещается

Запрещено:

- использовать print();
- писать SQL в Router;
- дублировать код;
- создавать циклические зависимости;
- нарушать слои DDD;
- изменять базу без миграций;
- использовать глобальные состояния без необходимости.

---

# Основной принцип

Код должен быть:

- читаемым;
- типизированным;
- расширяемым;
- тестируемым;
- соответствовать архитектуре проекта.
