# Карта средства измерений

## Назначение

Карта СИ описывает конкретный экземпляр средства измерений (`Device` / ORM `Instrument`) и не должна смешиваться с карточкой типа средства измерений (`InstrumentType`).

## Семантика полей

Для конкретного экземпляра СИ используются следующие значения:

| Поле карты | Источник | Пример |
|---|---|---|
| Наименование СИ | `Device.name` | `ВКТ-7`, `ТВ7`, `ТСРВ-043` |
| Тип СИ | `InstrumentType.name` | `Вычислитель количества теплоты`, `Преобразователь давления` |
| Модель СИ | `Device.modification` | `ВКТ-7-04` |
| Серийный номер | `Device.serial_number` | конкретный серийный номер экземпляра |

`InstrumentType.model` не является моделью конкретного экземпляра и не используется для поля «Модель СИ» в карте СИ.

`InstrumentType.measurement_type` также не является значением поля «Тип СИ» в карте СИ. Тип СИ определяется именем сущности `InstrumentType`.

## Backend contract

`Instrument` хранит собственное `name`, поскольку имя относится к экземпляру СИ, а не к типу.

API `DeviceCreate`, `DeviceUpdate` и `DeviceRead` передают `name` вместе с остальными полями карты.

Для существующих записей поле `name` временно допускает `NULL`, поскольку корректное наименование нельзя достоверно восстановить из серийного номера или типа без бизнес-данных.

## Frontend contract

Карта СИ отображает:

```text
Наименование СИ → device.name
Тип СИ          → instrumentType.name
Модель СИ       → device.modification
```

Редактирование карты изменяет поля конкретного `Device` и не изменяет `InstrumentType`.

## Пример

```text
Наименование СИ: ВКТ-7
Тип СИ: Вычислитель количества теплоты
Модель СИ: ВКТ-7-04
```

Это означает:

- `Device.name = "ВКТ-7"`;
- `InstrumentType.name = "Вычислитель количества теплоты"`;
- `Device.modification = "ВКТ-7-04"`.

## Архитектурное правило

Изменение карты конкретного СИ не должно изменять общие свойства `InstrumentType`, поскольку один тип может быть связан с несколькими экземплярами СИ.
