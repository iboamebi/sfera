# Модуль Audit

**Версия:** 1.1
**Дата актуализации:** 2026-07-16

---

# 1. Назначение

Audit обеспечивает регистрацию значимых действий пользователей и системных изменений в проекте «Сфера».

Модуль предназначен для:

- контроля изменений;
- расследования ошибок;
- сохранения истории операций;
- обеспечения прозрачности работы системы.

---

# 2. Основная сущность

```text
AuditLog
```

AuditLog является записью факта изменения или действия.

---

# 3. Данные аудита

Хранятся:

- пользователь;
- дата и время;
- объект изменения;
- тип операции;
- старое значение;
- новое значение;
- источник изменения.

---

# 4. Типы операций

Примеры:

```text
CREATE

UPDATE

DELETE

EXPORT

STATUS_CHANGE

LOGIN
```

---

# 5. Объекты аудита

Могут отслеживаться:

```text
Order

Verification

Repair

Device

WarehouseMovement

Document

User
```

---

# 6. Место в архитектуре

Audit является общесистемным механизмом.

Используется:

```text
Application

↓

Domain Events

↓

Audit Handler

↓

AuditLog
```

---

# 7. Связь с событиями

Значимые изменения могут создавать события:

```text
OrderCompleted

VerificationFinished

RepairCompleted

RoleChanged
```

На основании событий создаётся запись аудита.

---

# 8. Ограничения

Запрещается:

- изменять существующие записи аудита;
- удалять историю;
- использовать AuditLog как основное хранилище бизнес-данных.

---

# 9. Хранение

Таблица:

```text
audit_logs
```

История является только добавляемой.

---

# 10. Application Services

Основной сервис:

```text
AuditService
```

Операции:

```text
Create Audit Record

Get History

Search Events
```

---

# 11. Тестирование

Проверяются:

- создание записи;
- корректность объекта;
- фиксация пользователя;
- неизменяемость истории.

---

# 12. Главный принцип

Audit обеспечивает полную прослеживаемость действий и изменений в системе «Сфера».
