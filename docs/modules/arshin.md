# Модуль Arshin

**Версия:** 1.1
**Дата актуализации:** 2026-07-16

---

# 1. Назначение

Arshin реализует подготовку и контроль экспорта результатов поверки средств измерений в ФГИС «Аршин».

Модуль обеспечивает:

- подготовку данных;
- проверку обязательных полей;
- формирование экспортного файла;
- хранение истории отправок.

---

# 2. Место в бизнес-процессе

Экспорт выполняется после завершения поверки:

```text
Order

↓

OrderItem

↓

Verification

↓

Arshin Export
```

---

# 3. Основная сущность

```text
ArshinExport
```

ArshinExport хранит информацию о подготовленном или выполненном экспорте.

---

# 4. Статусы экспорта

Пример жизненного цикла:

```text
CREATED

↓

VALIDATED

↓

EXPORTED

↓

CONFIRMED
```

Возможное состояние ошибки:

```text
FAILED
```

---

# 5. Условия экспорта

Поверка может быть экспортирована только если:

- работа завершена;
- результат поверки заполнен;
- обязательные данные присутствуют;
- нет признака "не экспортировать в Аршин".

---

# 6. Поля экспорта

Используется строгая структура шаблона.

Заполняются:

| Колонка | Значение |
|---|---|
| A | Обозначение СИ |
| B | Серийный номер |
| C | Модификация |
| E | Дата поверки |
| F | Срок действия |
| H | Причина непригодности |
| K | Методика поверки |
| N | Владелец |

---

# 7. Составные средства измерений

Для комплексов и составных СИ используется:

```text
AF — Состав СИ
```

Значение формируется из состава поверяемого комплекса.

---

# 8. Правила результата

## Пригодно

```text
SUITABLE
```

Заполняются:

- дата поверки;
- срок действия.

---

## Непригодно

```text
UNSUITABLE
```

Заполняется:

- причина непригодности.

Срок действия не указывается.

---

# 9. Ограничение повторного экспорта

После успешного экспорта:

- сохраняется факт отправки;
- сохраняется дата;
- сохраняется пользователь;
- повторная отправка контролируется.

---

# 10. Domain Model

Основные компоненты:

```text
ArshinExport Entity

ArshinExportStatus

ArshinExportService

ArshinExportRepository
```

---

# 11. Application Services

Основной сервис:

```text
ArshinExportService
```

Операции:

```text
Validate Export

Create Export

Mark Exported

Get Export History
```

---

# 12. Infrastructure

Infrastructure отвечает за:

- работу с XLSM-шаблоном;
- сохранение файлов;
- интеграцию с внешними сервисами.

---

# 13. Документы

Экспортный файл:

```text
XLSM
```

Файл создаётся на основе утверждённого шаблона.

Изменение структуры шаблона требует проверки.

---

# 14. Тестирование

Проверяются:

- обязательность полей;
- корректность дат;
- обработка пригодности/непригодности;
- формирование XLSM;
- запрет неверного экспорта.

---

# 15. Главный принцип

Arshin является контролируемым каналом передачи юридически значимых результатов поверки и не изменяет исходные данные Verification.
