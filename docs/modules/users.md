# Модуль Users

Версия: 1.0

---

# Назначение

Модуль отвечает за управление пользователями системы, ролями, правами доступа и аутентификацией.

---

# Основные сущности

```
User
Role
Permission
UserRole
RolePermission
```

---

# Структура

```text
User
 │
 ├── UserRole
 │        │
 │        ▼
 │      Role
 │        │
 │        ▼
 │  RolePermission
 │        │
 │        ▼
 │   Permission
```

---

# User

Учетная запись пользователя системы.

Основные поля:

- логин;
- пароль (хэш);
- ФИО;
- организация;
- активность;
- дата создания.

---

# Role

Роль определяет набор разрешений пользователя.

Примеры ролей:

```
Administrator

Manager

Metrologist

Engineer

Storekeeper

Operator
```

---

# Permission

Минимальная единица доступа.

Примеры:

```
order.read

order.create

order.update

verification.export

warehouse.issue

user.manage
```

---

# UserRole

Связь пользователя с ролью.

Поддерживается назначение нескольких ролей одному пользователю.

---

# RolePermission

Связь роли и разрешения.

---

# Связи

```text
User
 │
 ▼
UserRole
 │
 ▼
Role
 │
 ▼
RolePermission
 │
 ▼
Permission
```

---

# Бизнес-правила

## Пользователь

Логин пользователя уникален.

---

## Пароль

В базе хранится только хэш пароля.

---

## Роли

Пользователь может иметь несколько ролей.

---

## Разрешения

Разрешения наследуются через роли.

---

## Удаление

Физическое удаление пользователей не выполняется.

Используется архивирование или деактивация.

---

## Авторизация

Все запросы к API проходят проверку подлинности пользователя.

---

## Проверка доступа

Доступ определяется наличием необходимого Permission.

# Ограничения

Запрещается:

- хранить пароли в открытом виде;
- изменять системные разрешения без миграции;
- удалять роли, используемые пользователями;
- удалять разрешения, назначенные ролям.

---

# Планируемое развитие

- JWT-аутентификация;
- Refresh Token;
- разграничение доступа по организациям;
- журнал входов;
- блокировка учетных записей;
- двухфакторная аутентификация;
- интеграция с LDAP/Active Directory.

---

# Основной принцип

Все действия пользователя в системе выполняются только в рамках назначенных ему ролей и разрешений.
