# Модуль Document

**Версия:** 1.1
**Дата актуализации:** 2026-07-16

---

# 1. Назначение

Document реализует управление документами в системе «Сфера».

Модуль обеспечивает:

- создание документов;
- хранение информации о документах;
- работу с шаблонами;
- связь документов с производственными процессами.

---

# 2. Место в бизнес-процессе

Документы создаются на основании выполненных операций:

```text
Order

↓

Production Process

↓

Document
```

---

# 3. Основные сущности

## Document

Экземпляр созданного документа.

Хранит:

- тип документа;
- дату создания;
- связь с объектом;
- состояние;
- ссылку на файл.

---

## DocumentTemplate

Шаблон документа.

Хранит:

- название;
- тип;
- структуру;
- версию.

---

# 4. Типы документов

Примеры:

```text
Order Document

Repair Act

Verification Certificate

Technical Report

Arshin Export File
```

---

# 5. Структура

```text
DocumentTemplate

↓

Document

↓

Storage
```

---

# 6. Хранение файлов

Большие файлы не хранятся в PostgreSQL.

В базе сохраняются:

- метаданные;
- путь;
- идентификатор хранилища;
- информация о создании.

---

# 7. Storage

Файловое хранилище отвечает за:

- сохранение файлов;
- получение файлов;
- контроль доступа.

---

# 8. Связь с заказом

Документы могут быть связаны:

```text
Order

OrderItem

Verification

Repair

Diagnostic
```

---

# 9. Domain Model

Основные компоненты:

```text

DocumentType Value Object

Storage Interface
```

# 10. Application Services

Основной сервис:

```text
DocumentService
```

Операции:

```text
Create Document

```

---

# 11. Repository

Интерфейс:

```text
DocumentRepository
```

Реализация:

```text
SQLAlchemyDocumentRepository
```

---

# 12. Версионирование

Документы могут иметь версии:

```text
Document v1

↓

Document v2

↓

Document v3
```

История изменений сохраняется.

---

# 13. Ограничения

Запрещается:

- удалять юридически значимые документы;
- изменять созданные документы без новой версии;
- хранить большие файлы в базе данных.

---

# 14. Тестирование

Проверяются:

- создание документа;
- связь с объектом;
- генерация из шаблона;
- сохранение истории;
- доступ к файлу.

---

# 15. Главный принцип

Document обеспечивает сохранение и воспроизводимость результатов производственной деятельности системы «Сфера».
