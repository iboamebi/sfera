# Модуль Price List

Версия: 1.0

---

# Назначение

Модуль предназначен для хранения прайс-листов организации, расчёта стоимости услуг и определения цен, применяемых при оформлении заказов.

---

# Основные сущности

```
PriceList
PriceListItem
```

---

# Структура

```text
PriceList
     │
     ▼
PriceListItem
```

---

# PriceList

Описывает прайс-лист организации.

Основные поля:

- наименование;
- дата начала действия;
- дата окончания действия;
- активность;
- комментарий.

---

# PriceListItem

Позиция прайс-листа.

Основные поля:

- прайс-лист;
- наименование услуги;
- тип услуги;
- стоимость;
- описание.

---

# Связи

```text
PriceList
     │
     ▼
PriceListItem
```

Один прайс-лист содержит множество позиций.

Каждая позиция принадлежит только одному прайс-листу.

---

# Типы услуг

Перечень типов определяется перечислением `ServiceType`.

Типичные категории:

```
Verification

Calibration

Repair

Diagnostic

Maintenance

Other
```

---

# Бизнес-правила

## Активность

В расчётах используется только активный прайс-лист.

---

## Стоимость

Стоимость услуги не может быть отрицательной.

---

## История

При изменении стоимости рекомендуется создавать новый прайс-лист, а не изменять архивный.

---

## Использование

Стоимость услуги фиксируется в заказе на момент его оформления и не изменяется при последующем изменении прайс-листа.

# Ограничения

Запрещается:

- использовать неактивный прайс-лист для новых заказов;
- создавать позиции без прайс-листа;
- задавать отрицательную стоимость;
- удалять прайс-лист, используемый активными заказами (рекомендуется архивирование).

---

# Планируемое развитие

Планируется поддержка:

- нескольких версий прайс-листов;
- автоматического выбора действующего прайс-листа по дате;
- расчёта стоимости заказа;
- скидок заказчиков;
- коэффициентов срочности;
- пакетных услуг;
- акций и специальных предложений.

---

# Основной принцип

Прайс-лист является единым источником стоимости услуг, а цена, применённая к заказу, должна сохраняться неизменной на протяжении всего жизненного цикла заказа.
