# Модуль Pricing

**Версия:** 1.1
**Дата актуализации:** 2026-07-16

---

# 1. Назначение

Pricing реализует управление стоимостью работ и материалов в системе «Сфера».

Модуль предназначен для:

- хранения прайс-листов;
- определения стоимости услуг;
- расчёта стоимости заказа;
- подготовки коммерческих документов.

---

# 2. Место в бизнес-процессе

Стоимость формируется в контексте заказа:

```text
Customer

↓

Order

↓

OrderItem

↓

Price Calculation
```

---

# 3. Основные сущности

## PriceList

Прайс-лист.

Хранит:

- название;
- период действия;
- статус;
- описание.

---

## PriceListItem

Элемент прайс-листа.

Хранит:

- услугу;
- материал;
- стоимость;
- единицу измерения.

---

# 4. Структура

```text
PriceList

↓

PriceListItem

↓

Service / Material
```

---

# 5. Принципы ценообразования

Стоимость должна определяться:

- действующим прайс-листом;
- типом работы;
- количеством;
- условиями заказчика.

---

# 6. Цена заказа

Стоимость заказа формируется из:

```text
OrderItem

+

Work Cost

+

Material Cost
```

---

# 7. Связь с производством

Pricing используется для:

- расчёта стоимости ремонта;
- расчёта стоимости поверки;
- формирования документов.

---

# 8. Domain Model

Основные компоненты:

```text
PriceList Entity

PriceListItem Entity

Money Value Object

PricingService
```

---

# 9. Application Services

Основной сервис:

```text
PricingService
```

Операции:

```text
Create Price List

Add Item

Calculate Price

Get Current Price
```

---

# 10. Repository

Интерфейсы:

```text
PriceListRepository

PriceListItemRepository
```

Реализация:

```text
SQLAlchemyPriceListRepository
```

---

# 11. Правила

Запрещается:

- изменять стоимость выполненной работы задним числом;
- удалять использованные цены;
- использовать неактивный прайс-лист.

---

# 12. История цен

Изменение стоимости должно сохраняться.

Используется:

- новая версия прайс-листа;
- архивирование старых записей.

---

# 13. API

Основные ресурсы:

```text
/price-lists

/price-list-items
```

---

# 14. Тестирование

Проверяются:

- создание прайс-листа;
- добавление позиций;
- выбор актуальной цены;
- расчёт стоимости заказа.

---

# 15. Главный принцип

Pricing обеспечивает прозрачное и воспроизводимое формирование стоимости работ и материалов.
